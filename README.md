# RIClaw

RIClaw is a Telegram-driven app generation system.

A user describes an app in Telegram, and RIClaw:
1. collects the request,
2. asks clarifying questions when needed,
3. assembles a starting app from templates and feature modules,
4. uses Codex to adapt and complete the app,
5. validates the result,
6. deploys it,
7. sends the live app back to the user,
8. supports future edits as revisions of the same app.

## What RIClaw Does

- Build a new app from Telegram
- Ask clarification questions before or during the build
- Track progress and stop a running build
- Deploy the finished app to Vercel
- Let users request app changes by replying to the delivery message
- Keep app history through projects and revisions
- Let users browse apps, revisions, and roll back to prior versions
